# projectfacts-tools-eval-dashboard

This repo hosts the **public dashboard** for the
[projectfacts-tools-eval](https://github.com/YuliiaKovalova/projectfacts-tools-eval)
private eval pipeline.

The dashboard is auto-published to the `gh-pages` branch by the
`Publish Dashboard` workflow in the eval repo after every successful
matrix run. The eval cases, ground-truth, and raw results stay private;
only the rendered HTML/JSON dashboard is hosted here.

Live site: https://yuliiakovalova.github.io/projectfacts-tools-eval-dashboard/
